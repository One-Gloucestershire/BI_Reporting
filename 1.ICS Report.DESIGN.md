# 1.ICS Report - Ultimate ICS Population Health & Commissioning Intelligence

**Vision:** The best-in-class Integrated Care System report for the NHS. Comprehensive, actionable, inequalities-focused, data-transparent, and commissioning-ready.

## Design Principles (from CLAUDE.md & AGENT.md)
- ICS-system level views + local drilldowns
- Multiple analytical lenses (inequality, risk, condition, environment, CYP)
- Clean executive with clear "The Ask"
- Best practice visuals: tableEx for narratives, proper wrapping, no name clashes
- Data lineage and catalog integration
- Prevention, wider determinants, environment, education
- Actionable for commissioners and providers
- Scalable patterns
